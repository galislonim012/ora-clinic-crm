# חיבור הסוכנת נוי (CloudChat) למערכת אורה CRM - שאלה 5

הסוכנת נוי (משאלה 4) מחוברת למערכת אורה CRM (משאלה 3) בשני מסלולים, דרך n8n.

- **הסוכנת בשידור חי:** https://console.thecloud.chat/p/web/3tfvd3qwtvl00ntb?ref=-uflow::f297963s4881989::live::284831 (נפתח דף לבן, לוחצים על הבועה הירוקה בפינה)
- **המערכת:** https://ora-clinic-crm-theta.vercel.app (כפתור "כניסה כבודק (מנהלת)"), מסך "קריאות"

## איך זה בנוי

```
נוי (CloudChat)
  └─ כלי (AI Function) ─ מפעיל זרימה שקטה (Workflow)
        └─ External Request ─► n8n Webhook (נעול בכותרת x-agent-key)
              └─ HTTP Request ─► Supabase: פעולה במסד הנתונים (RPC)
              ◄─ תשובה חוזרת באותה דרך
        └─ AI Function Result ─► נוי עונה ללקוחה לפי התשובה בלבד
```

| חלק | מה יש בו |
|---|---|
| `n8n/noy-open-ticket.json` | תהליך n8n לפתיחת קריאה (אפשר לייבא ל-n8n) |
| `n8n/noy-next-appointment.json` | תהליך n8n לשליפת התור הבא |
| `../supabase/migrations/0005_agent_api.sql` | שתי הפעולות במסד הנתונים: `agent_open_ticket`, `agent_next_appointment` |
| `screenshots/` | צילומי מסך של כל השלבים |

הקבצים לא מכילים סיסמאות או מפתחות. המפתח של Supabase שמור רק בכספת של n8n, והסיסמה של ה-Webhook שמורה רק ב-n8n וב-CloudChat.

## מסלול א - פתיחת קריאת שירות

1. נוי אוספת שם, טלפון ותיאור, חוזרת על הפרטים ומבקשת אישור מפורש.
2. הכלי `open_ticket` מפעיל את הזרימה "נוי - שליחת קריאה למערכת", ששולחת את שלושת הפרטים ל-n8n.
3. n8n מפעיל את `agent_open_ticket`:
   - מאתר את הלקוחה לפי טלפון (מנרמל מקפים ו-972). אם לא קיימת, יוצר אותה.
   - פותח קריאה בסטטוס **חדשה**, בערוץ "סוכן AI", משויכת לרותם (מנהלת).
   - מחזיר מספר קריאה (`call_ref`).
4. מספר הקריאה נשמר בשדה `crm_ticket_result`. אם לא חזר מספר (שמירה נכשלה או המערכת לא זמינה), נשמר `FAILED`.
5. נוי מוסרת את מספר הקריאה **רק אם חזר**. ב-`FAILED` היא אומרת שהייתה תקלה ושהפנייה לא נשמרה, ולא ממציאה מספר.

## מסלול ב - התור הבא

1. לקוחה שואלת "מתי התור הבא שלי?". נוי מבקשת טלפון (או משתמשת בטלפון שכבר נמסר).
2. הכלי `get_next_appointment` מפעיל את הזרימה "נוי - בדיקת התור הבא", ששולחת את הטלפון ל-n8n.
3. n8n מפעיל את `agent_next_appointment`: מוצא את **התור הקרוב בעתיד שאינו מבוטל**, ומחזיר תאריך, שעה (שעון ישראל) וסוג טיפול.
4. אם אין תור עתידי, חוזר `has_appointment: false`, ונוי אומרת "לא נמצא תור עתידי ברשומות שנבדקו", בלי לנחש.
